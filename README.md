# aucubin/homebrew-tap

Homebrew tap for my tools.

```sh
brew install --cask aucubin/tap/zmk-battery-applet
```

| Cask | Description |
|------|-------------|
| [zmk-battery-applet](https://github.com/aucubin/zmk-battery-applet) | Menu bar applet showing the battery level of ZMK split keyboards |

Casks are updated automatically by the release workflow of each project.
